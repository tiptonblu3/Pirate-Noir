# Sunken-Cost

Sunken Cost is a Pirate game where the player is grappling on and boarding ships then has to fight off waves of enemies on the ship in order to collect loot once all the waves are defeated the player has a few seconds to loot as much as they can before the ship sinks once the player collects the loot or if the ship is taking on too much water the player can grapple to the next ship to fight the next waves.

Controls

Mouse/Right Stick: Look

WASD/Left stick: Movement

Hold L.Shift/Left Stick: Sprint

Space/South Button: Jump

M1/Right Trigger: Attack

M2/Left Trigger: Grapple

E/West Button: Interact

R/North Button: Heal
